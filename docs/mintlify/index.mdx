PrioriCode is the open source AI coding agent built by [Prioritech Indonesia Optima](https://prioritech.co.id). It lives in your terminal, reads your codebase, runs your tools, and ships your code — one conversation at a time.

<Note>
  PrioriCode is a fork of [OpenCode](https://github.com/anomalyco/opencode). It keeps the full core — TUI, agents,
  providers, plugins, MCP, GitHub integration — and adds features like cross-session coordination and tunable context
  compaction.
</Note>

## What you get

- **Terminal-native.** Run `prioricode` anywhere you already work. No IDE lock-in — though [editors](/extending/editors) can host it too.
- **Model-agnostic.** Anthropic, OpenAI, Google, Bedrock, OpenRouter, local endpoints — switch per session, bring your own keys. See [providers](/getting-started/providers).
- **Safe by default.** Every edit, command, and network call goes through a [permission system](/using/permissions) you configure — or a sandbox you can require.
- **Scriptable.** `prioricode run --format json` turns the agent into a pipe-friendly build step. See [headless mode](/using/headless).
- **Open source.** Read it, fork it, ship it on [GitHub](https://github.com/Prioritech-Indonesia-Optima/prioricode).
