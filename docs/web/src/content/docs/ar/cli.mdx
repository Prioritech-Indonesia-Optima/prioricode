يبدأ CLI الخاص بـ PrioriCode افتراضيا واجهة [TUI](/docs/tui) عند تشغيله بدون أي معاملات.

```bash
prioricode
```

كما يدعم أيضا أوامر موثقة في هذه الصفحة، ما يتيح لك التفاعل مع PrioriCode برمجيا.

```bash
prioricode run "Explain how closures work in JavaScript"
```

---

### tui

بدء واجهة المستخدم terminal (TUI) الخاصة بـ PrioriCode.

```bash
prioricode [project]
```

#### الخيارات

| الخيار                                   | المختصر | الوصف                                                             |
| ---------------------------------------- | ------- | ----------------------------------------------------------------- |
| <nobr><code>{"--continue"}</code></nobr> | `-c`    | متابعة الجلسة الأخيرة                                             |
| <nobr><code>{"--session"}</code></nobr>  | `-s`    | معرّف الجلسة للمتابعة                                             |
| <nobr><code>{"--fork"}</code></nobr>     |         | تفريع الجلسة عند المتابعة (يستخدم مع `--continue` أو `--session`) |
| <nobr><code>{"--prompt"}</code></nobr>   |         | الموجّه المراد استخدامه                                           |
| <nobr><code>{"--model"}</code></nobr>    | `-m`    | النموذج المراد استخدامه بصيغة provider/model                      |
| <nobr><code>{"--agent"}</code></nobr>    |         | الوكيل المراد استخدامه                                            |
| <nobr><code>{"--port"}</code></nobr>     |         | المنفذ الذي يتم الاستماع عليه                                     |
| <nobr><code>{"--hostname"}</code></nobr> |         | اسم المضيف الذي يتم الاستماع عليه                                 |

### attach

إرفاق terminal بخادم الواجهة الخلفية لـ PrioriCode قيد التشغيل بالفعل، والذي تم تشغيله عبر الأمرين `serve` أو `web`.

```bash
prioricode attach [url]
```

يتيح ذلك استخدام واجهة TUI مع واجهة خلفية لـ PrioriCode تعمل عن بعد. على سبيل المثال:

```bash
# ابدأ خادم الواجهة الخلفية للوصول عبر الويب/الجوال
prioricode web --port 4096 --hostname 0.0.0.0

# في محطة طرفية (terminal) أخرى، اربط TUI بالواجهة الخلفية قيد التشغيل
prioricode attach http://10.20.30.40:4096
```

#### الرايات

| الراية                                   | المختصر | الوصف                                                                                 |
| ---------------------------------------- | ------- | ------------------------------------------------------------------------------------- |
| <nobr><code>{"--dir"}</code></nobr>      |         | دليل العمل الذي ستبدأ منه واجهة TUI                                                   |
| <nobr><code>{"--continue"}</code></nobr> | `-c`    | متابعة آخر جلسة                                                                       |
| <nobr><code>{"--session"}</code></nobr>  | `-s`    | معرّف الجلسة للمتابعة                                                                 |
| <nobr><code>{"--fork"}</code></nobr>     |         | تفريع الجلسة عند المتابعة (استخدمه مع `--continue` أو `--session`)                    |
| <nobr><code>{"--password"}</code></nobr> | `-p`    | كلمة مرور المصادقة الأساسية (الافتراضي `PRIORICODE_SERVER_PASSWORD`)                  |
| <nobr><code>{"--username"}</code></nobr> | `-u`    | اسم مستخدم المصادقة الأساسية (الافتراضي `PRIORICODE_SERVER_USERNAME` أو `prioricode`) |

### auth

أمر لإدارة بيانات الاعتماد وتسجيل الدخول لمزودي الخدمة.

```bash
prioricode auth [command]
```

---

#### login

يعتمد PrioriCode على قائمة المزودين في [Models.dev](https://models.dev)، لذا يمكنك استخدام `prioricode auth login` لتهيئة مفاتيح API لأي مزود ترغب باستخدامه. يتم حفظ ذلك في `~/.local/share/prioricode/auth.json`.

```bash
prioricode auth login
```

عند تشغيل PrioriCode يقوم بتحميل المزودين من ملف بيانات الاعتماد، وكذلك أي مفاتيح معرّفة في متغيرات البيئة لديك أو في ملف `.env` ضمن مشروعك.

---

#### list

يسرد جميع المزودين الذين تم توثيقهم كما هم محفوظون في ملف بيانات الاعتماد.

```bash
prioricode auth list
```

أو النسخة المختصرة.

```bash
prioricode auth ls
```

---

#### logout

يسجلك خارج مزود عبر حذفه من ملف بيانات الاعتماد.

### models

عرض جميع النماذج المتاحة من المزودين المُهيأين.

```bash
prioricode models [provider]
```

يعرض هذا الأمر جميع النماذج المتاحة عبر المزودين المُهيأين لديك بصيغة `provider/model`.

هذا مفيد لتحديد اسم النموذج الدقيق الذي ستستخدمه في [تهيئتك](/docs/config/).

يمكنك اختياريا تمرير معرّف مزود لتصفية النماذج حسب ذلك المزود.

```bash
prioricode models anthropic
```

#### الرايات

| الراية                                  | الوصف                                                         |
| --------------------------------------- | ------------------------------------------------------------- |
| <nobr><code>{"--refresh"}</code></nobr> | تحديث ذاكرة التخزين المؤقت للنماذج من models.dev              |
| <nobr><code>{"--verbose"}</code></nobr> | استخدام مخرجات أكثر تفصيلا للنماذج (تشمل بيانات مثل التكاليف) |

استخدم الراية `--refresh` لتحديث قائمة النماذج المخزنة مؤقتا. يفيد ذلك عند إضافة نماذج جديدة إلى مزود وتريد رؤيتها في PrioriCode.

```bash
prioricode models --refresh
```

### run

تشغيل prioricode في وضع غير تفاعلي عبر تمرير موجه مباشرة.

```bash
prioricode run [message..]
```

هذا مفيد للبرمجة النصية والأتمتة، أو عندما تريد إجابة سريعة دون تشغيل واجهة TUI كاملة. على سبيل المثال.

```bash "prioricode run"
prioricode run Explain the use of context in Go
```

يمكنك أيضا الإرفاق بمثيل `prioricode serve` قيد التشغيل لتجنّب زمن الإقلاع البارد لخوادم MCP في كل تشغيل:

```bash
# ابدأ خادمًا بلا واجهة في محطة طرفية واحدة
prioricode serve

# في محطة طرفية أخرى، شغّل الأوامر التي ترتبط به
prioricode run --attach http://localhost:4096 "Explain async/await in JavaScript"
```

#### الرايات

| الراية                                   | المختصر | الوصف                                                                                 |
| ---------------------------------------- | ------- | ------------------------------------------------------------------------------------- |
| <nobr><code>{"--command"}</code></nobr>  |         | الأمر المراد تشغيله؛ استخدم الرسالة كوسائط                                            |
| <nobr><code>{"--continue"}</code></nobr> | `-c`    | متابعة الجلسة الأخيرة                                                                 |
| <nobr><code>{"--session"}</code></nobr>  | `-s`    | معرّف الجلسة للمتابعة                                                                 |
| <nobr><code>{"--fork"}</code></nobr>     |         | تفريع الجلسة عند المتابعة (يستخدم مع `--continue` أو `--session`)                     |
| <nobr><code>{"--share"}</code></nobr>    |         | مشاركة الجلسة                                                                         |
| <nobr><code>{"--model"}</code></nobr>    | `-m`    | النموذج المراد استخدامه بصيغة provider/model                                          |
| <nobr><code>{"--agent"}</code></nobr>    |         | الوكيل المراد استخدامه                                                                |
| <nobr><code>{"--file"}</code></nobr>     | `-f`    | ملف/ملفات لإرفاقها بالرسالة                                                           |
| <nobr><code>{"--format"}</code></nobr>   |         | التنسيق: default (منسق) أو json (أحداث JSON خام)                                      |
| <nobr><code>{"--title"}</code></nobr>    |         | عنوان للجلسة (يستخدم موجهًا مقتطعًا إن لم تُحدَّد قيمة)                               |
| <nobr><code>{"--attach"}</code></nobr>   |         | الإرفاق بخادم prioricode قيد التشغيل (مثل http://localhost:4096)                      |
| <nobr><code>{"--password"}</code></nobr> | `-p`    | كلمة مرور المصادقة الأساسية (الافتراضي `PRIORICODE_SERVER_PASSWORD`)                  |
| <nobr><code>{"--username"}</code></nobr> | `-u`    | اسم مستخدم المصادقة الأساسية (الافتراضي `PRIORICODE_SERVER_USERNAME` أو `prioricode`) |
| <nobr><code>{"--dir"}</code></nobr>      |         | دليل التشغيل، أو المسار على الخادم البعيد عند الإرفاق                                 |
| <nobr><code>{"--variant"}</code></nobr>  |         | متغير النموذج (جهد الاستدلال الخاص بالمزود)                                           |
| <nobr><code>{"--thinking"}</code></nobr> |         | عرض كتل التفكير                                                                       |
| <nobr><code>{"--port"}</code></nobr>     |         | منفذ الخادم المحلي (الافتراضي منفذ عشوائي)                                            |

### serve

بدء خادم PrioriCode بدون واجهة للوصول عبر API. راجع [توثيق الخادم](/docs/server) لواجهة HTTP الكاملة.

```bash
prioricode serve
```

يشغّل هذا خادم HTTP يوفّر وصولا عبر API لوظائف prioricode دون واجهة TUI. اضبط `PRIORICODE_SERVER_PASSWORD` لتفعيل مصادقة HTTP الأساسية (اسم المستخدم الافتراضي `prioricode`).

#### الرايات

| الراية                                   | الوصف                                     |
| ---------------------------------------- | ----------------------------------------- |
| <nobr><code>{"--port"}</code></nobr>     | المنفذ الذي يتم الاستماع عليه             |
| <nobr><code>{"--hostname"}</code></nobr> | اسم المضيف الذي يتم الاستماع عليه         |
| <nobr><code>{"--mdns"}</code></nobr>     | تفعيل اكتشاف mDNS                         |
| <nobr><code>{"--cors"}</code></nobr>     | أصول/منشأات إضافية للمتصفح للسماح بـ CORS |

### stats

```bash
prioricode stats
```

#### الرايات

| الراية                                  | الوصف                                                                     |

### upgrade

تحديث prioricode إلى أحدث إصدار أو إلى إصدار محدد.

```bash
prioricode upgrade [target]
```

للترقية إلى أحدث إصدار.

```bash
prioricode upgrade
```

للترقية إلى إصدار محدد.

```bash
prioricode upgrade v0.1.48
```

#### الرايات

| الراية                                 | المختصر | الوصف                                                       |
| -------------------------------------- | ------- | ----------------------------------------------------------- |
| <nobr><code>{"--method"}</code></nobr> | `-m`    | طريقة التثبيت المستخدمة: curl أو npm أو pnpm أو bun أو brew |

## متغيرات البيئة

يمكن تهيئة PrioriCode باستخدام متغيرات البيئة.

| المتغير                                 | النوع   | الوصف                                                       |
| --------------------------------------- | ------- | ----------------------------------------------------------- |
| `PRIORICODE_AUTO_SHARE`                 | boolean | مشاركة الجلسات تلقائيا                                      |
| `PRIORICODE_GIT_BASH_PATH`              | string  | مسار ملف Git Bash التنفيذي على Windows                      |
| `PRIORICODE_CONFIG`                     | string  | مسار ملف التهيئة                                            |
| `PRIORICODE_CONFIG_DIR`                 | string  | مسار دليل التهيئة                                           |
| `PRIORICODE_CONFIG_CONTENT`             | string  | محتوى تهيئة JSON مُضمّن                                     |
| `PRIORICODE_DISABLE_AUTOUPDATE`         | boolean | تعطيل التحقق التلقائي من التحديثات                          |
| `PRIORICODE_DISABLE_PRUNE`              | boolean | تعطيل تنقية البيانات القديمة                                |
| `PRIORICODE_DISABLE_TERMINAL_TITLE`     | boolean | تعطيل تحديث عنوان terminal تلقائيا                          |
| `PRIORICODE_PERMISSION`                 | string  | تهيئة أذونات JSON مُضمّنة                                   |
| `PRIORICODE_DISABLE_DEFAULT_PLUGINS`    | boolean | تعطيل الإضافات الافتراضية                                   |
| `PRIORICODE_DISABLE_LSP_DOWNLOAD`       | boolean | تعطيل تنزيل خوادم LSP تلقائيا                               |
| `PRIORICODE_ENABLE_EXPERIMENTAL_MODELS` | boolean | تفعيل النماذج التجريبية                                     |
| `PRIORICODE_DISABLE_AUTOCOMPACT`        | boolean | تعطيل ضغط السياق تلقائيا                                    |
| `PRIORICODE_DISABLE_CLAUDE_CODE`        | boolean | تعطيل القراءة من `.claude` (الموجه + المهارات)              |
| `PRIORICODE_DISABLE_CLAUDE_CODE_PROMPT` | boolean | تعطيل قراءة `~/.claude/CLAUDE.md`                           |
| `PRIORICODE_DISABLE_CLAUDE_CODE_SKILLS` | boolean | تعطيل تحميل `.claude/skills`                                |
| `PRIORICODE_DISABLE_MODELS_FETCH`       | boolean | تعطيل جلب النماذج من مصادر بعيدة                            |
| `PRIORICODE_FAKE_VCS`                   | string  | مزود VCS وهمي لأغراض الاختبار                               |
| `PRIORICODE_CLIENT`                     | string  | معرّف العميل (الافتراضي `cli`)                              |
