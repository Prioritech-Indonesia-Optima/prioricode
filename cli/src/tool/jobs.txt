Inspect and control background jobs. Launch background shell commands with the bash tool's `background: true` parameter (and background subagent tasks via the task tool). Read progress, wait for completion, or stop a job.

Actions:
- "list": every job — id, type, status, title. Use it to discover ids.
- "output": one job's output since `cursor` (byte offset, so repeats never re-send bytes). Finished jobs include status and exit result.
- "wait": block until finish or `timeout` (ms); returns status plus output since `cursor`. Prefer it over chaining "output" calls.
- "kill": terminate a running shell job; it becomes "cancelled". Completed jobs cannot be killed.

Rules:
- Finished background commands are announced automatically — never sleep or poll in a loop; end your response or do other work and the result arrives.
- Jobs survive between turns; they end on exit, kill, or session teardown.
- Full output history is also a plain file (`outputPath` from start time) for Grep/Read.
