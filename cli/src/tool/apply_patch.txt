Edit files with a file-oriented patch format — all changes in one call.

When: several related file changes belong in one step.
How — the patch format:

*** Begin Patch
[ file sections ]
*** End Patch

Each section starts with an action header:
- *** Add File: <path> — new file; following lines all start with `+`.
- *** Delete File: <path> — remove file; nothing follows.
- *** Update File: <path> — patch in place; optional *** Move to: <path> rename, @@ context markers, `-` old lines, `+` new lines.

Example:

```
*** Begin Patch
*** Add File: hello.txt
+Hello world
*** Update File: src/app.py
*** Move to: src/main.py
@@ def greet():
-print("Hi")
+print("Hello, world!")
*** Delete File: obsolete.txt
*** End Patch
```
