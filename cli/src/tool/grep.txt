- Fast content search, any codebase size (regex, powered by ripgrep).
- Pattern like "log.*Error" or "function\s+\w+"; include filters files by glob ("*.js", "*.{ts,tsx}"); path is the search directory.
- Returns file paths and line numbers of matches.
- Counting or aggregating matches: run `rg` via bash directly. Never pipe shell `grep`/`find`/`cat`.
