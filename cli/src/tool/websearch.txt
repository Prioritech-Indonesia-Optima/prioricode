Real-time web search via the session's provider — returns content from the most relevant sites. Use it for anything beyond the knowledge cutoff: current events, recent releases, changing facts.

- numResults controls result count (default 8); context length is tuned for LLM consumption.
- livecrawl (when available): 'fallback' (cached first) or 'preferred' (live crawl).
- type (when available): 'auto', 'fast', 'deep'. Domain filtering supported.

The current year is {{year}}. Append the year to searches for recent information.
- "latest AI news" → query "AI news {{year}}", not an older year.
