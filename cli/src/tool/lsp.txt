Code intelligence via Language Server Protocol.

Operations:
- goToDefinition / goToImplementation: where a symbol is defined / implemented
- findReferences: all references to a symbol
- hover: docs and type info at a position
- documentSymbol: all symbols in a file
- workspaceSymbol: project-wide symbols matching query (empty query = all; filePath here only selects/starts the server, it is not sent in the LSP request)
- prepareCallHierarchy / incomingCalls / outgoingCalls: call hierarchy at a position

Position args (all operations): filePath, line (1-based), character (1-based).

Requires a configured LSP server for the file type — otherwise errors.
